# 0.1.0 worklog

## done

- `field.js`: seeded value noise (perm table), 2-octave potential, turbulence as curl of
  potential — divergence-free so the ship swirls instead of piling into attractors.
- `sim.js`: headless state/step; modes produce turbulence damp scales combined by min();
  beacon beam pressure centers on axis, guide valley pulls back to the curve, buoys damp
  in radius; hull wear above safe-accel threshold, idle/thrust energy drain, gate open cost;
  result codes incl. "at gate, can't afford to open".
- `render.js`: field streak grid (damped by active modes, so calm corridors are visible),
  beams, guide valley band, buoys, gates, ship, HUD bars + end-of-run stats overlay.
- `main.js` + `index.html`: live mode checkboxes, turbulence/cone/falloff sliders, seed,
  keyboard (WASD/arrows, Space buoy, R reroll). file://-friendly classic scripts.
- `experiments/difficulty.js`: naive autopilot over 5 mode configs x 24 seeds.

## validation

- `node -c` clean on all four js files.
- experiment run (see `experiments/logs/difficulty-0.1.0.md`): raw 21% win / avg wear 95,
  buoys 54% / 80, beacons 100% / 2.2, guide 100% / 0.1, all 100% / 0.3.
- tuned turbStrength 230→300, coneDamp 0.12→0.18, buoyRadius 110→125 to separate the modes
  (at 230 even raw won 46% and both aided modes had exactly 0 wear — nothing to compare).

## known limitations

- autopilot flies the straight gate-gate line = beacon axis, so beacon results are optimistic;
  guide/beacon ~equal in the table but feel very different to a human.
- beacons currently calm the *whole* cone length; no range falloff.
